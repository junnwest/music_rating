# Security Policy

## Reporting a vulnerability

If you've found a security vulnerability in sillajuku, please report it privately rather than opening a public issue.

Email **admin@sillajuku.com** with:
- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any proof-of-concept code, if applicable

We aim to acknowledge reports within 48 hours and to resolve confirmed vulnerabilities as quickly as the fix allows. We'll keep you updated on progress and credit you (if you'd like) once it's resolved.

## Scope

This covers the sillajuku web app, iOS app, and backend (Supabase database, API routes, catalog pipeline). Please don't test against production data belonging to other users, and don't run automated scanners against the live site without contacting us first.

## Disclosure

Please give us a reasonable amount of time to fix an issue before disclosing it publicly. We don't currently run a bug bounty program.
